プライバシーポリシー

Rakuten Trade MY 助手（パッケージ名: com.assistant.stocktrading）
最終更新日: 2026-06-21

本アプリは Rakuten Trade および証券会社の公式アプリではなく、非提携です。 注文の送信・自動売買は行いません。投資助言ではなく、参考情報に基づく分析支援ツールです。

1. はじめに

本ポリシーは、マレーシア株（Bursa Malaysia）を中心とした投資分析・意思決定支援アプリ「Rakuten Trade MY 助手」（以下「本アプリ」）における情報の取り扱いを説明します。当方はユーザーアカウントを運営せず、当方が管理するバックエンドサーバーに個人プロフィールを蓄積する仕組みはありません。

2. 端末内に保存する情報

  • API キー（OpenAI、Twelve Data、News API、X API 等）— ユーザーが任意で入力。OS の暗号化ストレージ（SecureStore）に保存。
  • ポートフォリオ・約定記録・練習モードの取引データ — 端末内ストレージ（AsyncStorage）のみ。
  • アプリ設定（表示モード、通知設定、ガイド進捗等）— 端末内のみ。
  • Rakuten 取引履歴インポートで確定した取引候補 — 端末内のみ（OCR 元画像そのものは永続保存しません）。

3. ネットワーク経由で送信する情報

ユーザーが各機能を利用した場合、HTTPS で以下の第三者サービスへリクエストが送信されます。

  • OpenAI — AI コンシェルジュ、材料分析、および（任意機能）Rakuten 取引履歴スクリーンショットの OCR（Vision API）。送信内容には、ユーザーが入力した質問文、銘柄コード・分析コンテキスト、および OCR 利用時はユーザーが選択した画像（base64 エンコード）が含まれる場合があります。
  • Twelve Data / Yahoo Finance 等 — 株価・チャート取得（銘柄シンボル等）。
  • News API / X API / Reddit RSS 等 — ニュース・SNS 材料（検索クエリ、銘柄名等）。
  • KLSE Screener 等 — 公開 HTML ページの取得（URL リクエスト）。

当方はユーザーデータを第三者に販売しません。送信はユーザー操作に基づく機能利用時に限られます。各サービスのプライバシーポリシーもご確認ください。

4. 画像（OCR インポート）について

  • ユーザーが Rakuten 取引履歴のスクリーンショットを自ら選択した場合にのみ、写真ライブラリへアクセスします（Android 権限: READ_MEDIA_IMAGES / expo-image-picker）。
  • 選択された画像は端末上で読み込まれ、OCR 実行時に OpenAI Vision API へ送信されます。当方サーバーへの画像アップロードは行いません。
  • OCR 元画像を当方が端末外に保存することはありません。解析結果（構造化された取引行）は、ユーザーが確認・確定したうえで端末内に保存されます。
  • 本機能は OpenAI API キー設定時の任意機能です。

5. 収集しない情報

  • アカウント登録（メール、氏名、電話番号）は不要です。
  • 位置情報、連絡先、マイク録音ファイルの収集は行いません。
  • 広告 ID や Firebase Analytics 等の第三者分析 SDK は導入していません（2026-06-21 時点）。
  • 決済情報は収集しません（ブローカー連携・注文執行なし）。

6. Android 権限

  • WAKE_LOCK / FOREGROUND_SERVICE / FOREGROUND_SERVICE_DATA_SYNC — 株価・材料の定期更新（フォアグラウンドサービス）。
  • POST_NOTIFICATIONS — AI・材料通知（ユーザー許可後）。
  • READ_MEDIA_IMAGES — Rakuten 取引履歴 OCR 用のスクリーンショット選択（ユーザー操作時のみ）。

7. 利用目的

  • 株価・ニュース・AI 分析機能の提供
  • ポートフォリオ管理（端末内）
  • 取引履歴のインポート支援（OCR・手入力・AI 自然言語）
  • 通知の配信（ユーザー許可時）

8. データの保存とセキュリティ

  • API キーは端末の SecureStore に保存します。
  • その他のデータは端末内 AsyncStorage に保存し、当方サーバーへ一括アップロードしません。
  • 通信は TLS（HTTPS）を使用します。

9. データの削除

  • 設定画面から API キーを個別に削除できます。
  • 「すべてリセット」でアプリデータを削除できます。
  • Android のアプリ情報 → ストレージ消去、またはアンインストールで端末上のデータを削除できます。

10. 子どものプライバシー

本アプリは 13 歳未満を対象としていません。

11. 変更

本ポリシーは必要に応じて更新します。重要な変更はアプリまたは Google Play ストアページで告知します。

12. お問い合わせ

プライバシーに関するお問い合わせ: k416my@gmail.com

Privacy Policy

Rakuten Trade MY Assistant (package: com.assistant.stocktrading)
Last updated: 2026-06-21

This app is not affiliated with Rakuten Trade or any broker. It does not place orders or automate trading. It is an analysis and decision-support tool, not investment advice.

1. Overview

This policy describes how the Rakuten Trade MY Assistant app handles information. We do not operate user accounts or a backend server that stores your personal profile.

2. Data stored on your device

  • API keys you optionally enter (OpenAI, Twelve Data, News API, X API, etc.) — encrypted secure storage.
  • Portfolio, trade records, practice mode — local storage only.
  • App settings and notification preferences — local storage only.
  • Confirmed Rakuten import transactions — local storage only (source OCR images are not kept permanently).

3. Data sent over the network

When you use features, HTTPS requests may be sent to third-party services including:

  • OpenAI — AI concierge, material analysis, and (optional) Rakuten transaction screenshot OCR (Vision API). This may include your questions, symbol/analysis context, and when you run OCR, the image you selected (base64-encoded).
  • Twelve Data / Yahoo Finance — market data (symbols).
  • News API / X API / Reddit RSS — news and social material (queries).
  • KLSE Screener and similar sites — public HTML pages.

We do not sell your data. Transmission occurs only when you use the relevant feature.

4. Images (OCR import)

  • Photo library access occurs only when you choose a Rakuten Trade transaction history screenshot (READ_MEDIA_IMAGES / expo-image-picker).
  • The selected image is read on-device and sent to OpenAI Vision API when you run OCR. We do not upload images to our own servers.
  • We do not persistently store OCR source images off-device. Parsed rows are saved locally only after you review and confirm.
  • This feature is optional and requires your OpenAI API key.

5. What we do not collect

  • No account registration, email, name, or phone number required.
  • No location, contacts, or microphone recordings.
  • No advertising ID or third-party analytics SDK (as of 2026-06-21).
  • No payment information.

6. Android permissions

  • Foreground service permissions — periodic price and material updates.
  • Notifications — with your permission.
  • READ_MEDIA_IMAGES — screenshot picker for optional Rakuten OCR import.

7. Your choices

  • Delete API keys in Settings.
  • Reset all app data or uninstall the app.

8. Children

This app is not directed at children under 13.

9. Changes

We may update this policy. Material changes will be communicated via the app or Play Store listing.

10. Contact

Privacy inquiries: k416my@gmail.com
