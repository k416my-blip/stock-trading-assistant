# 実機スモークテストチェックリスト

個人用の毎日運用前に、実機で以下を確認してください。アプリ内「個人用運用」→「実機チェックリスト」でも同内容を表示できます。

| # | 項目 | 確認内容 | ☐ |
|---|------|----------|---|
| 1 | 新規インストール | 初回起動でクラッシュせず、空のポートフォリオが表示される | |
| 2 | アプリ再起動 | 保有・設定が再起動後も残る | |
| 3 | オフライン | オンライン起動 → データ表示 → 機内モードON → キャッシュ・AsyncStorage・バナー（Expo Goは完全オフライン起動は本番APKで確認） | |
| 4 | APIキー未設定 | キーなしでも起動・保有閲覧可。更新は失敗メッセージのみ | |
| 5 | APIクォータ超過 | 429後も保有が消えず、バックオフ後に回復する | |
| 6 | ステール価格 | STALE 表示があり、危険な執行がブロックされる | |
| 7 | 保有追加 | 練習買付で保有が増える | |
| 8 | 保有編集 | 価格・銘柄・市場の手動修正が保存される | |
| 9 | 保有削除 | 確認ダイアログ後に削除。取り消しが使える | |
| 10 | 練習売買 | 買付・売却が記録され残高が合う | |
| 11 | 売買連打 | 確定連打で重複注文にならない | |
| 12 | 破損復旧 | 破損データでもクラッシュせず拒否/復旧する | |
| 13 | 機密削除 | 確認後にAPIキー等が削除される | |
| 14 | 安全モード | 復旧失敗時に安全モードと診断が表示される | |

## バックアップ（推奨）

週1回: **個人用運用** → **バックアップをエクスポート** → ファイルを安全な場所に保存

## 毎日（1タップ）

**個人用運用** → **ヘルスチェック** → `OK` なら通常利用、`Warning/Critical` なら推奨アクションを実施
